This is an example of a password-protected page.

Note About Password Protection Methods:

Server-Side (Recommended) - Using middleware.js:

  • No changes needed to HTML files
  • Password protection is automatic
  • More secure
  • Just commit middleware.js, package.json, and vercel.json

Client-Side (Simple) - Using password-protection-simple.js:

  • Uncomment the script tag in the <head> section above
  • Update the password in password-protection-simple.js
  • Less secure (password visible in source)
  • Easier to implement

Your Protected Content Goes Here

If you're seeing this page, either:

  1. You've successfully authenticated with the password, or
  2. Password protection is not yet enabled

How to Enable Protection:

For Server-Side Protection:

  1. Ensure middleware.js, package.json, and vercel.json are committed
  2. Add this page to the PROTECTED_PAGES array in middleware.js
  3. Set the PROTECTED_PAGES_PASSWORD environment variable in Vercel
  4. Deploy to Vercel

For Client-Side Protection:

  1. Uncomment the script tag in the <head> section of this file
  2. Update the password in password-protection-simple.js
  3. Commit and deploy
